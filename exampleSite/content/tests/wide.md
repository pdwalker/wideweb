Front matter: `layout: wide`.

Expected at width ≥ 1280px: left sidebar **collapsed** (the wide layout
defaults it off, but `sidebar.show: true` still opts back in), right sidebar
**shown** (this page has headings), main width = window − 16rem. Below 1280px
the right column is responsive-hidden too, and the page spans **100% of the
window** at any width — this layout used to be capped at 90rem and never
rendered the TOC at all; WideWeb removed both deviations.
